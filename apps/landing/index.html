The problem

To know you are a student, a site makes you hand over your address.

Then it keeps it, mails it, and leaks it when it is breached. And it still cannot stop one person taking the free tier fifty times — ana+1@gmail.com and a.n.a@gmail.com are one inbox and two rows.

How it works

Three steps.

01

The site shows a code

It expires in minutes and works on that site only.

02

You send yourself an email

From the address you want to prove. Your provider signs it — that signature is the proof, and only you can produce it.

03

The claim is spent, once

Your mailbox becomes an unguessable value on Midnight. The site sees the domain and a first-time flag. Never the address.

The SDK

Two calls in your own backend.

const { code } = mailproof.startVerification()

const result = await mailproof.verify(eml)

if (result.ok && result.tier === 'STUDENT' && !result.alreadyClaimed) {
  await db.user.update({ where: { id }, data: { plan: 'PRO' } })
}

You choose which domains earn which tier, and what to grant. The SDK never sees a benefit and you never see an address. Read the quickstart →

Everything is open. Run all of it yourself.
